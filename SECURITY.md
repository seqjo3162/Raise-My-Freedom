# Security Policy

## Что делает эта штука

Запускается от root, ставит правила в таблицу `nat` и переключает системный DNS на
локальный форвардер. Если ты это запустил — так и задумано, уязвимостью не считается.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | :white_check_mark: |

## Что стоит сообщить

Используй **Security → Report a vulnerability** на странице репозитория, а не
публичный issue.

Интересует вот это:

- обход, при котором содержимое трафика уходит мимо релея — то есть перехват
  получается неполным и пользователь этого не понимает;
- выход за пределы `127.0.0.1` — перехват по замыслу локальный, наружу ничего
  уходить не должно;
- невозможность откатить правила: `scripts/cleanup.sh` не снимает то, что сам
  установил, и оставляет систему в нерабочем состоянии.

## Что уязвимостью не является

Блокировка, которую инструмент не обошёл. Подмена DNS, RST-инъекции, DPI — это то,
ради чего он написан, а не то, что в нём сломано.

Единственное исключение — если из-за бага перехват становится виден наружу,
например форвардер слушает не на localhost. Это уже да, пиши.
